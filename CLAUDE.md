# Правила работы с проектом

## Структура файлов

- Весь сайт — в одном файле `index.html`. CSS и JS — inline, внутри того же файла.
- Никаких внешних библиотек (React, Vue, Bootstrap, jQuery и т.д.). Только чистый HTML, CSS, JS.
- Шрифты можно подключать через Google Fonts CDN — это не считается библиотекой.
- Не создавай новые файлы без необходимости. Если нужно создать файл — сначала объясни зачем.

## Дизайн

- Тема: тёмный фон, светлый текст.
- Акцентный цвет: изумрудный зелёный (`#059669`) с голубым вторичным (`#06b6d4`). Не менять на другие цвета без явной просьбы.
- Все страницы и компоненты — адаптивные. Сначала проверяй как выглядит на мобильном (320–390px), потом на десктопе.
- Не ломай существующий визуальный стиль при добавлении нового.

## Стиль текста на сайте

- Простой и дружеский язык — как будто объясняешь знакомому.
- Без канцелярита: не «осуществляем разработку», а «делаем сайты».
- Короткие предложения. Без лишних слов.

## Процесс работы

- Перед созданием нового файла — сначала расскажи что планируешь сделать и зачем, дождись подтверждения.
- Перед большими изменениями в `index.html` — кратко опиши что изменишь.
- Не рефакторь и не «улучшай» то, о чём тебя не просили.
- Коммиты делай только когда явно попросят.
