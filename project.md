# MargoNeiro — Лендинг-портфолио

## Что это за проект

Продающий лендинг-портфолио для Маргариты (MargoNeiro) — цифрового специалиста из Владивостока. Сайт создаёт доверие и конвертирует посетителей в заявки на бесплатную консультацию. Не галерея работ и не визитка — каждый блок снимает конкретное возражение потенциального клиента.

---

## Для кого

**Основная аудитория — владелец малого бизнеса:**
- Компания 2–30 человек, хочет сайт / приложение / автоматизацию рутины
- Боится долго, дорого, непонятно; обжигался на фрилансерах и агентствах
- Не знает что такое ИИ-агент, но слышал это слово
- ~60% приходит с мобильного

**Вторичная аудитория:**
- Стартап-фаундер, которому нужен MVP
- Маркетолог / операционный директор, ищущий подрядчика по заданию руководства

---

## Страницы

### Есть сейчас
- **`index.html`** — единственный файл, вся страница целиком

  Секции внутри:
  1. **Навигация** — sticky, blur при скролле, hamburger на мобильном
  2. **Hero** — заголовок + подзаголовок + CTA-кнопки + статистики + AI-виджет-демо
  3. **Проблема** — 3 карточки болей клиента
  4. **Услуги** — сайты / приложения / ИИ-агенты
  5. **Отзывы** — 3 карточки + статистическая полоса
  6. **Портфолио** — 3 проекта (сайт, ИИ-агент, приложение)
  7. **Обо мне** — текст + монограмма + факты
  8. **Процесс** — 5 шагов работы
  9. **FAQ** — аккордеон с ценами и ответами на возражения
  10. **Контакт** — форма + контактные методы
  11. **Footer** — навигация + соцсети + индикатор доступности

### Планируются
- Пока только главная страница. Страницы кейсов, блог и другие разделы не запланированы.

## Дизайн

**Тема:** тёмная, технологичная, с изумрудным акцентом

**Цвета:**
- Фон: `#0a0a0f` (глубокий чёрный)
- Поверхности: `#12121a` / `#1a1a26`
- Акцент 1: `#059669` (изумрудный)
- Акцент 2: `#06b6d4` (голубой)

**Шрифты:**
- Заголовки: **Philosopher** (serif, курсивный)
- Текст: **Manrope** (гуманистический sans-serif)
- Логотип: **Cinzel Decorative**
- Декоративный: **Allura** (cursive, используется для монограммы и акцентных фраз)
- Моноширинный (теги, лейблы): JetBrains Mono / системный стек

**Ключевые визуальные решения:**
- Анимированные mesh-gradient orbs в hero
- Лейблы секций с переливающимся shimmer-эффектом (зелёный ↔ голубой)
- Пульсирующие кольца вокруг главной CTA-кнопки
- AI-виджет с последовательным typewriter-эффектом (4 строки: Q→A→Q→A)
- Градиентная монограмма «MRG» вместо фотографии
- Noise texture overlay поверх всей страницы (opacity 3.5%)
- Scroll-reveal анимации через IntersectionObserver

## Технический стек

| Что | Как |
|-----|-----|
| Фреймворк | Нет — единый `index.html` |
| Стили | Inline `<style>` (CSS custom properties) |
| Скрипты | Inline `<script>` (vanilla JS) |
| Шрифты | Google Fonts CDN |
| Анимации | CSS keyframes + IntersectionObserver |
| Деплой | GitHub (репозиторий `my-landing`) |
| Миграция на фреймворк | Не решено |

## Статус

Лендинг в активной разработке. Основная структура и визуал готовы. Предстоит:
- Заменить плейсхолдеры (имя «Алексей», тестовые отзывы, цифры статистик) на реальный контент
- Добавить реальные проекты в портфолио (пока формулировки условные, без скриншотов)
- Настроить отправку формы (сейчас форма имитирует отправку)
- Прописать реальные контакты (Telegram, email)
